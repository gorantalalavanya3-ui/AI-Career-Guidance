# AI-Based Career Guidance System

A Diploma CSE mini-project built with Python and Streamlit.

## Run on Windows
1. Open Command Prompt in this folder.
2. Activate your virtual environment if you created one:
   `venv\Scripts\activate`
3. Install dependencies:
   `python -m pip install -r requirements.txt`
4. Run:
   `python -m streamlit run app.py`
5. Open the local address shown in the terminal (usually http://localhost:8501).

## Project modules
- Student profile and assessment
- Rule-based career recommendation
- Career match indicator
- Skill-gap analysis
- Four-week starter learning roadmap
- CSV export

## Important academic description
This version uses a transparent rule-based scoring method, not a trained machine-learning model. The term "AI-based" in the project title refers to the decision-support/recommendation concept. In your report and viva, clearly explain the current implementation honestly. Future work can add a properly trained and evaluated ML model.
